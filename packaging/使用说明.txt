昊云网络巡检助手 - 使用说明(绿色免安装版)
================================================================

一、启动与退出
  1. 双击「启动巡检助手.exe」,直接打开软件小工具窗口,全程不需要浏览器。
  2. 关闭软件窗口即退出程序。
  3. 无需安装任何软件,本文件夹可放在 U 盘、桌面或任意目录运行。

二、文件夹说明
  启动巡检助手.exe    程序本体(双击打开小工具窗口)
  config\devices.yaml 首次启动时导入的初始设备清单(演示数据,只导入一次;
                     之后设备档案在软件「设备管理」中维护,改这个文件不再生效)
  config\rules\       巡检规则文件(启动时自动合并加载全部规则;一般无需修改)
  config\ai.yaml      AI 大模型分析配置(可选,详见文件内注释)
  config\smtp.yaml    邮件分发配置(可选;默认没有此文件,需要时按下方第 10 条手工创建)
  config\auth.yaml    网页远程访问的登录账号(默认 admin/admin123,本地小工具无需登录)
  data\               设备与客户档案、任务记录、巡检历史(请勿随意删除或外发)
  output\             巡检报告输出目录(HTML / Word / Excel / PDF)

三、基本使用流程
  1. 双击打开小工具后,先在「设备管理」添加设备(IP、用户名、密码、厂商型号),
     台账较多时用「批量导入」导入 Excel/CSV/Word 台账;新建或编辑设备时点
     「自动识别」,只填地址和账号密码即可自动判定厂商与型号。
  2. 「客户管理」可登记甲方公司,设备按归属客户统计(可选)。
  3. 「巡检任务」勾选设备 -> 开始巡检,任务自动后台执行并刷新进度。
  4. 「报告管理」查看、预览、导出报告(Word/Excel/PDF),双击报告行直接预览
     (汇总、风险项、检查项、AI 结论,均在软件窗口内显示)。
     任务列表里某台设备显示"采集异常"时,打开报告可看到每台设备的具体原因;
     全部设备都连不上时任务会标为失败,而不是"完成"。
  5. 配置好 AI 大模型后(「系统设置」),巡检完成后自动 AI 分析,
     报告带健康评分、关键发现、处置建议与结论摘要;已有报告也可一键重跑分析。
  6. 「系统设置」可查看产品信息、MIT 开源协议(允许二次修改开发);
     AI 配置内置 DeepSeek/智谱/通义/Kimi/豆包/文心/星火/混元 等国内厂商预设,
     选厂商自动填接口地址,支持"测试连通"验证 Key 是否可用;
     发现新版本点「下载并安装」->「重启并安装」自动完成升级,
     不会覆盖 config 与 output 中的数据,旧程序自动备份。
  7. 「系统设置 -> 定时巡检」可安装 Windows 计划任务,每周三 02:00 或
     每月 1 日 02:00 自动巡检界面里已启用的全部设备,结果在「报告管理」查看。

四、常见问题
  1. 双击后提示"Windows 已保护你的电脑":
     点「更多信息」->「仍要运行」;或在杀毒软件中选择信任/加入白名单。
     本程序只在本机运行,不会向外发送数据(AI 分析除外,需自行配置)。
  2. PDF 报告需要电脑装有 Microsoft Word 或 LibreOffice 之一;
     两者都没有时 HTML/Word/Excel 报告不受影响。
  3. AI 分析需要能访问互联网,并填入大模型 API Key
     (支持 DeepSeek、智谱、通义、Kimi、本地 Ollama 等 OpenAI 兼容接口)。
  4. 手机/同事电脑想远程访问界面:命令行执行
     set PATROL_HOST=0.0.0.0
     启动巡检助手.exe --web
     用本机 IP 访问(网页登录已默认开启,默认账号 admin / admin123,
     请到「系统设置 -> 账号安全」修改后使用)。
  5. 网页模式默认界面地址: http://127.0.0.1:8765/ui
  6. 忘记网页登录密码:关闭程序后删除 config\auth.yaml,重新启动即恢复默认账号
     admin / admin123,登录后请立即重新设置新密码。
  7. API/Web 采集报"HTTPS 证书校验失败":设备(如深信服 NGAF)多用自签名证书,
     在「设备管理 -> 编辑」勾选「跳过 HTTPS 证书校验」即可。
  8. 命令行批量巡检:启动巡检助手.exe run
     巡检界面里已启用的全部设备(与界面共用同一份设备档案)。
     退出码:0 正常 / 2 存在异常项 / 3 全部设备都没采集到,便于脚本判断。
  9. 检查项显示 UNKNOWN(无法判定):表示该项没能得到可靠结论——设备回显格式
     暂未被识别(中兴/迈普/USG/SecPath 等解析器在现场验证前可能出现),
     或设备不支持该命令、账号权限不足、回显为空。
     UNKNOWN 不代表设备正常或异常,报告不会把它算作"通过"。
     遇到格式未识别请保留报告用于适配:报告中该项下方的"原始输出"块
     (或 output\ 下同名 .html / .json 报告文件)包含完整设备回显,
     把报告文件回传即可离线适配解析器。
 10. 邮件分发(可选):在 config\ 下新建 smtp.yaml,内容形如
       enabled: true
       host: smtp.example.com
       port: 465
       ssl: true
       username: 发信账号
       password: 发信授权码
       from: 巡检助手 <发信账号>
       cc_boss: [抄送邮箱]
     并在「客户管理」给客户填写接收邮箱(多个用分号分隔);导出报告时会询问是否发送。
