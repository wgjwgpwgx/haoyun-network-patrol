# 昊云网络巡检助手

### 把网络巡检从"一天"压缩到"一键"

登设备、敲命令、贴截图、拼报告——一次全网巡检，一名工程师一整天就耗进去了。下周，还要再来一遍。

昊云网络巡检助手把这活儿交给软件：**你选设备，它跑巡检、判状态、出报告。**

## 它能做什么

**一键全网巡检**
7 家全国产厂商（华为 / H3C / 锐捷 / 深信服 / 迪普 / 中兴 / 迈普）、10+ 类设备，SSH / Telnet / Web / API / SNMP 多通道自动采集：CPU、内存、告警、端口、光模块……一次任务几十台设备，产出**一份整体报告**，问题设备一目了然。

**专业报告，直接交付**
HTML 交互版、Word 正式版（含封面与签字盖章页）、Excel 设备台账、PDF——巡检报告拿去汇报、归档、交甲方，无需二次加工。

**YAML 规则引擎判定**
健康状态不是拍脑袋：每类指标一条条规则配置，正常 / 关注 / 异常有据可查；判定依据的原始回显整行保留，随时回溯。

**AI 智能分析（可选）**
接入大模型后，AI 结合设备原始回显给出整体评估与逐台点评，辅助定位隐患；不配 Key 也完整可用。

**台账与自动发现**
Excel 台账智能导入，子网扫描自动发现在线设备——从"维护一张表"变成"维护一个系统"。

**让数据积累价值**
定时巡检（每周 / 每月自动跑）、历史对比、趋势预测。

## 为什么敢用

- **结果如实** — 设备连不上就说连不上，读不懂的回显标"无法判定"，绝不冒充"检查通过"
- **双击即用** — Windows 绿色包，零安装零依赖，U 盘拷走就能跑
- **数据不出内网** — 全本地运行，设备凭据在 Windows 下系统级加密落盘
- **开源可审计** — MIT 协议，代码全公开，欢迎审查与二次开发
- **1080 项自动化测试**，每次代码变更都跑 Windows / Linux / macOS 三平台 CI

## 谁在用

网络工程师、企业 IT 运维、系统集成商——所有需要定期给网络"做体检"的团队。

## 开始使用

- **Windows**：[下载绿色包](https://gitee.com/nmghywx/xjzs/releases)，解压双击即用
- **信创 Linux**（银河麒麟/统信 UOS，x86_64/aarch64）：同一页面下载 tar.gz，解压后 `./patrol-assistant --web` 即是网页界面
- **Linux / macOS**：`pip install -e .` 后运行，支持 Web 远程模式（带登录认证）
- **源码与文档**：[gitee.com/nmghywx/xjzs](https://gitee.com/nmghywx/xjzs)（国内）· [GitHub 镜像](https://github.com/wgjwgpwgx/haoyun-network-patrol)
