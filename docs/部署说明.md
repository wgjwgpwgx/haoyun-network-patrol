# 部署说明

> 适用:昊云网络巡检助手 patrol v0.1.0+(2026-11-14 基线,907 用例)
> 本文档面向部署/运维人员;工程师日常操作请阅读同目录《快速上手指南》。

---

## 1. 安装与启动

### 1.1 绿色免安装包(推荐)

```
dist/昊云网络巡检助手/
├── 启动巡检助手.exe          ← 双击=桌面小工具(无浏览器/无黑框)
├── 启动巡检助手.exe --web    ← 命令行启动 Web 模式(自动开浏览器)
├── config/                    ← 设备/客户/规则/AI/SMTP 配置
│   ├── devices.yaml           ← 旧版设备配置(首次启动自动迁移到 SQLite)
│   ├── customers.yaml         ← 旧版客户配置(同上)
│   ├── rules/                 ← 巡检规则 YAML(可编辑)
│   │   ├── default.yaml       ← 基础健康规则(R001-R013)
│   │   ├── baseline_dengbao.yaml ← 等保 2.0 安全基线(D001-D008)
│   │   └── {设备类型}.yaml     ← 厂商专项规则
│   ├── ai.yaml                ← AI 大模型分析配置(默认关)
│   ├── auth.yaml              ← Web 登录账号(默认 admin/admin123)
│   ├── smtp.yaml              ← 邮件分发配置(默认关)
│   └── report_style.yaml     ← 报告样式(乙方署名/封面色)
├── data/
│   └── patrol.db              ← SQLite 统一仓库(设备/客户/任务/审计)
├── output/
│   ├── patrol_*.html/json     ← 巡检报告(平铺,网页报告页依赖)
│   ├── {客户}/{年月}/         ← 导出报告自动归档
│   ├── knowledge/             ← 设备知识库(经验沉淀)
│   ├── configs/               ← 配置快照(diff 对比用)
│   └── screenshots/           ← Web 采集截图
└── 使用说明.txt               ← 工程师指南
```

### 1.2 源码方式

```bash
cd E:\巡检助手
python -m pip install -e .
python -m patrol.launcher           # 桌面小工具
python -m patrol.launcher --web    # Web 模式(默认 127.0.0.1:8765)
python -m patrol                    # CLI 全量巡检(注意:这不是打开程序)
```

**必须从项目根目录启动**:所有相对路径(config/、output/、data/)按当前目录解析。

### 1.3 Web 模式远程访问

```bash
set PATROL_HOST=0.0.0.0 && python -m patrol.launcher --web
```
开放到局域网前务必:确认已设置登录密码(auth.yaml 默认开启)+ 防火墙仅放行运维网段。

## 2. 数据层(SQLite 统一仓库)

| 数据 | 存储位置 | 说明 |
|---|---|---|
| 设备档案 | data/patrol.db `devices` 表 | 凭据 DPAPI 加密落盘(内存明文),兼容旧明文 |
| 客户档案 | data/patrol.db `customers` 表 | 含报告接收邮箱字段 |
| 巡检任务 | data/patrol.db `tasks` 表 | 持久化,重启不丢 |
| 操作审计 | data/patrol.db `audit_log` 表 | REST 写操作自动记录;`GET /audit` 查询 |
| 巡检历史 | data/patrol_history.db | 含指标值(趋势图数据源);上期复查/连续期次 |
| 知识库 | output/knowledge/{客户}/{设备}/*.yaml | 全量回显语料 |

**首次启动自动迁移**:若 config/devices.yaml 存在且 SQLite 库为空,自动导入(幂等)。

## 3. 安全配置

### 3.1 登录认证(默认开启)

- 首次启动自动播种 admin/admin123,请在桌面「系统设置→账号安全」修改
- config/auth.yaml 设 `enabled: false` 可显式关闭(不推荐)
- 会话 12 小时有效

### 3.2 凭据加密

- 设备档案中的 password/super_password/api_token 使用 **Windows DPAPI** 绑定当前用户加密落盘
- 拷贝到其他电脑/其他用户无法解密(设计如此)
- 旧明文文件兼容读取(无 `enc$` 前缀按明文处理)

### 3.3 只读双保险

- 命令表:全部 display/show/dir/compare 只读命令,逐条评审入库
- 执行层:SSH 下发前只读校验器(危险动词黑名单+白名单前缀),写命令在发出前即被拦截
- 测试固化:全 SSH 驱动命令表扫描测试,任何人加入写命令→测试立即失败

### 3.4 SNMP 采集安全

- SNMP v2c 只读,固定 OID 白名单(sysName/sysDescr/sysUpTime/ifTable)
- password 字段填 community(建议甲方提供只读团体字)

## 4. 巡检能力

### 4.1 登录方式(六通道)

| 方式 | 端口 | 凭据 | 适用 |
|---|---|---|---|
| SSH | 22 | 用户名+密码+可选super | 主通道 |
| Telnet | 23 | 同上 | 老设备 |
| SNMP v2c | 161 | community(填密码字段) | 甲方不给账号 |
| Console 串口 | - | host=COM口,port=波特率 | 带外应急 |
| Web 页面 | 443 | 用户名+密码 | 防火墙/AC |
| API | 443 | token | 深信服 NGAF |

### 4.2 厂商与设备类型(7 厂商 10 类型)

| 厂商 | 设备类型 | 通道 | 检查项 |
|---|---|---|---|
| H3C | Comware/S7506E/SecPath | SSH/Telnet/SNMP | 14-19 |
| 华为 | VRP 交换机/USG 防火墙 | SSH/Telnet/SNMP | 15-18 |
| 锐捷 | RGOS 交换机 | SSH/Telnet | 8 |
| Cisco | IOS 交换机/路由器 | SSH/Telnet | 15 |
| Juniper | Junos | SSH/Telnet | 8 |
| 深信服 | NGAF 防火墙 | Web/API | 6 |
| 迪普 | FW 防火墙 | Web | 4 |

### 4.3 检查项(九大类)

基础信息 / 硬件环境(温度/光模块DDM/电源/风扇) / 资源(CPU/内存/Flash) / 接口链路 / 路由协议(OSPF) / 表项规模(ARP) / 安全合规(等保8项) / 日志告警(含配置一致性) / 网络拓扑(LLDP)

### 4.4 并发巡检

默认 3 路(环境变量 `PATROL_CONCURRENCY=1` 退回串行保护老设备)。

## 5. 报告体系

| 模板 | 格式 | 读者 | 特点 |
|---|---|---|---|
| 正式汇报版 | Word/PDF | 甲方领导 | 封面+签字盖章页,无原始回显 |
| 工程明细版 | Word/PDF/HTML | 工程师 | 全明细+原始回显+配置diff+拓扑图 |
| 台账表格版 | Excel | 甲方归档 | 三Sheet(台账/矩阵/异常跟踪) |

报告含:健康评分(五类加权+critical否决)、安全基线达标率、上期问题复查、配置变更对比、网络拓扑(LLDP)、图表(饼/条/趋势)。

导出的 Word/Excel 自动归档到 `output/{客户}/{年月}/`。

## 6. 设备知识库

- 巡检自动沉淀全部回显;支持导入旧报告(Word/txt/粘贴/JSON)
- 解析器 Copilot:知识库回显→AI 生成规则→确认入库→下次巡检自动生效
- 模拟设备:知识库设备一键起本地 Telnet 模拟(演示/培训/自测)

- 邮件分发:config/smtp.yaml + 客户档案邮箱字段

## 9. 常见问题

| 问题 | 解决 |
|---|---|
| 真机连接超时 | 跑 `python scripts/preflight_check.py` |
| SNMP 无回显 | 检查 community + SNMP 服务 + 防火墙 UDP 161 |
| PDF 下载失败 | 需装 Word/LibreOffice |
| 数据备份 | 备份 data/patrol.db + config/ 目录 |
| 报告样式修改 | 编辑 config/report_style.yaml |
| 模拟器 netmiko 连不上 | netmiko telnet 对模拟环境过严(真机正常);可用 telnet 命令行验证 |
