# 网络巡检工具产品化方案
**——对标国内外头部产品的融合路线(纯方案,不含代码)**

> 场景定位:为网络工程师(乙方维保/运维外包)提供轻量巡检工具——SSH/Web 任一方式登录设备,自动采集基础维护明细,自动生成正式巡检报告,交付甲乙双方留存。
> 编制日期:2026-11-13 · 基于当前 patrol 项目现状(桌面+网页双形态、7 厂商 10 设备类型、规则引擎、AI 分析)

---

## 一、需求解读

您描述的工作流本质是:**"手工登录→复制回显→粘贴 Word"的自动化替代**,交付物是**甲乙双方留存的正式巡检报告**。拆解为四个核心诉求:

| 诉求 | 含义 | 隐含要求 |
|---|---|---|
| 多方式登录 | SSH / Web 二选一即可 | 设备凭据管理(含 super 密码)、只读安全 |
| 基础维护明细 | CPU/内存/接口/电源风扇/日志/配置 | 原始回显留存(甲方工程师认"截图式"证据) |
| 电子文件报告 | 自动排版成正式文档 | Word/PDF 为主,甲方台账习惯要 Excel |
| 甲乙双方留存 | 报告是商务交付物 | 封面(甲方/乙方/合同号/日期)、签字栏、盖章位、客户维度归档 |

## 二、国内外头部产品横向对比

### 2.1 综合对比表

| 产品 | 形态 | 巡检报告能力 | 借鉴点 | 不适合您的原因 |
|---|---|---|---|---|
| **华为 iMaster NCE**(eSight 演进) | 重型平台 | 云巡检组件:定时/按需巡检、租户维度报告、健康评估+优化建议 | 健康评分、优化建议、按客户出报告 | 需服务器部署、绑定华为生态、成本高 |
| **新华三 U-Center** | 重型平台 | 智能巡检+报表中心 | 巡检模板可自定义 | 同上 |
| **深信服 SAM** | 平台+云 | 全网健康巡检 | 风险分级呈现 | 绑定深信服设备生态 |
| **Cisco Catalyst Center** | 平台 | 每设备合规审计报告(CIS 基线) | 合规基线库、逐设备合规状态汇总 | 思科生态、许可昂贵 |
| **SolarWinds NCM** | C/S 平台 | 配置备份+合规策略+计划报告 | **配置留存与变更 diff**、定时报告邮件分发 | 英文生态、按节点收费 |
| **ManageEngine NCM** | 平台 | CIS 基线自动审计、SNMP 安全检查 | 基线规则库产品化 | 需部署服务器 |
| **BackBox** | 平台 | 合规报告自动生成并**发送给客户** | 报告自动邮件推送 | 国外商业、贵 |
| **Nautobot Golden Config**(开源) | 自建框架 | 备份/diff/合规三合一,来源可信(SoT) | 备份-对比-合规一体化的架构思想 | 需 Docker+多个组件,运维成本高 |
| **Nornir + Netmiko**(开源) | 代码框架 | 无内置报告,全靠自写 | 纯 Python 批量采集的底座(我们已在用 netmiko) | 面向开发者,非工程师 |
| **网上 Python 巡检脚本** | 脚本 | 多为回显堆砌到 txt/xls | 无 | 无规则判定、无正式报告、无凭据管理 |

### 2.2 结论

- **头部平台的长处**集中在:定时调度、配置备份 diff、基线库、报告自动分发、健康评分;
- **它们的共同盲区**正是您的定位:**轻量、单机、双击即用、离线可用、不挑厂商、免费/低价**——没有一家头部产品做"工程师 U 盘里的巡检工具";
- 您项目已具备的底座(多厂商采集、规则引擎、Word/HTML/PDF 报告、客户归属、AI 总结、桌面+网页、绿色免安装)**已领先于民间脚本一个身位**,差的是头部产品的四件"增值武器"(见第四节)。

## 三、可取长处提炼(取长)

| # | 长处 | 来源 | 对您的价值 |
|---|---|---|---|
| 1 | **正式报告封面与签字栏**(甲方/乙方/合同号/巡检人/审核人/盖章区/日期) | 维保行业惯例、SolarWinds 报告模板 | 报告直接就是商务交付物,免手工二次排版——**最贴合"留存甲乙双方"** |
| 2 | **配置留存 + 变更 diff** | SolarWinds NCM / Oxidized / Nautobot | 巡检时自动备份 running-config,两期报告对比配置变更——维保纠纷高发点的硬证据 |
| 3 | **定时巡检 + 报告自动分发** | iMaster NCE / BackBox | 每周自动巡检并把报告邮件发给甲方接口人——"无人值守月度巡检报告"是乙方核心竞争力 |
| 4 | **安全基线库** | ManageEngine/Cisco(CIS 基线) | 把规则引擎的 YAML 规则按"等保 2.0/CIS"组织成可勾选基线包,报告体现"合规达标率" |
| 5 | **健康评分 + 优化建议** | iMaster NCE | 已有 AI 分析 ✓,可加 0-100 健康分 |
| 6 | **Excel 批量台账** | 甲方财务/台账习惯 | 设备明细+检查结果一表导出,甲方归档最爱 |
| 7 | **SNMP 兜底采集** | 各网管平台标配 | 个别不给登录账号的甲方,SNMP 只读也能采基础指标 |
| 8 | **报告双份输出**(给甲方的正式版 / 给工程师的原始回显版) | BackBox | 一键出"精简版(结论+建议)+ 完整版(含回显)"两份 |

## 四、融合方案(分三期,均基于现有底座增量实现)

### P0「正式交付」(1~2 天工作量)——直接补齐"留存甲乙双方"
1. **报告封面正式化**:封面页增加 甲方名称(自动取客户管理)、乙方名称(产品信息里配置)、合同编号、巡检日期/周期、巡检人/审核人签字栏、双方盖章区;Word/PDF 均生效。
2. **Excel 台账报告**:新增 ExcelReporter——设备明细(客户/型号/版本/IP)+ 检查结果矩阵 + 风险清单三个 Sheet。
3. **报告双版本**:同一巡检一键产出 精简版(无原始回显,给甲方领导)+ 完整版(含回显,给双方工程师)。

### P1「维保硬证据」(3~5 天)
4. **配置留存与变更对比**:巡检时自动保存 running-config 快照(output/configs/按设备按日期),报告新增"与上期配置差异"章节(diff 高亮增删行)。
5. **基线规则包**:规则文件按"基础健康/安全基线(等保对齐)/厂商专项"三个可勾选包组织,报告输出合规达标率(如"安全基线 12/15 项达标")。

### P2「无人值守」(3~5 天)
6. **定时巡检**:桌面版加计划任务(每周/每月指定时间自动对启用的设备跑巡检)。
7. **报告自动归档+邮件分发**:按"客户/年月"目录归档;SMTP 配置后自动把正式版报告发甲方接口人、完整版发乙方邮箱。

### 暂不做(明确取舍)
- SNMP 采集、多设备并发、Web 大屏 —— 与"轻量单机"定位冲突,等真机反馈后再议;
- 对标 Nautobot 的来源可信/数字孪生 —— 企业级平台能力,不属于本工具战场。

---

## 五、推荐组合(明星方案)

> **"U 盘里的维保巡检官"** = 现有底座(多厂商采集+规则+AI+双形态) + P0 正式报告(封面/签字/盖章/Excel/双版本) + P1 配置 diff 与基线包 + P2 定时与邮件分发

这个组合下,工程师的月度巡检动作变成:**双击打开 → 选客户 → 一键巡检 → 自动生成两版报告 → 自动归档发邮件**。对比现状(手工登录复制粘贴 2~4 小时/次),单次节省 90% 以上,且每份报告都是可直接盖章的商务交付物——这就是与头部平台错位竞争的最优价值点。
