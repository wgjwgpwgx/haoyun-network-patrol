# 智能台账导入 与 巡检报告模板预制 方案
**(2026-11-13 定稿 · 附头部厂商模板依据 · 首项已开工实施)**

> 两个专项:① 设备台账智能导入(Word/Excel 野格式自动识别字段);② 巡检完成时 3 套可选报告模板(预制头部厂商版式)。

---

## 一、智能台账导入(工程师手里的用户名密码表直接用)

### 1.1 设计原则(对"100% 识别"的工程实现)

机器自动识别 + **预览确认**双保险:高置信度自动映射,低置信度标黄由工程师 3 秒确认/修改映射后入库——**最终入库正确率 100%**(头部产品导入向导的标准形态)。

### 1.2 双层识别引擎

**第一层·表头同义词**(归一化:全半角/空格/大小写)
| 字段 | 同义词集(节选) |
|---|---|
| 登录地址 | IP、地址、管理地址、管理IP、IP地址、设备IP、运维地址、host、address |
| 用户名 | 用户名、账号、帐号、登录名、登录账号、设备账号、username、user |
| 一级密码 | 密码、口令、一级密码、登录密码、登录口令、设备密码、password、pwd |
| super 密码 | super密码、super、二级密码、特权密码、enable密码、enable password |
| 设备名称 | 设备名、设备名称、名称、主机名、hostname、别名 |
| 登录方式 | 登录方式、接入方式、协议、方式、login method |
| 单位 | 单位、客户、公司、甲方、归属、客户名称 |
| 其余 | 厂商/品牌、端口、备注/说明 |

**第二层·内容特征**(表头缺失/不齐时,采样前 20 行):
- 地址列:IPv4 正则命中 >60% → 强特征(0.9)
- 登录方式列:值 ∈ {ssh,telnet,web,api,console} → 强特征
- 端口列:1~65535 且常见值(22/23/443) → 强特征
- 用户名/密码列:启发式(短串无空格 vs 混合字符长串)→ 0.6~0.7 标黄
- **两列密码无表头**:内容层无法区分一级/super → 标黄请工程师指定(诚实边界)

### 1.3 支持格式与流程

| 格式 | 读取方式 | 说明 |
|---|---|---|
| .xlsx/.xlsm | openpyxl | 首选 |
| .csv | 内置(UTF-8/GBK 自动探测) | — |
| .docx | python-docx 取表格 | 用户密码表常为 Word 表格 |
| .xls(97-2003) | 提示另存为 xlsx | openpyxl 不支持老格式,提示文案给出转换步骤 |

流程:**选文件 → 自动解析+识别 → 预览表(列映射+置信度+缺失必填提示+问题行标黄)→ 工程师确认映射 → 入库(挂到选定单位)**。行级校验:地址合法性/必填三要素/单位存在性;失败行跳过并计数,不阻塞整批。

## 二、巡检完成时的 3 套可选报告模板(预制版式)

> 依据:华为官方巡检表"巡检项/检查标准/巡检结果/备注"四列范式、维保月报惯例(月度巡检出具系统检查报告)、运维巡检模板章节框架(概述/范围/健康评估)。巡检完成弹窗提示:**"本次巡检报告已就绪,请选择输出模板(可多选)"**。

### 模板一《正式汇报版》(Word/PDF,5~8 页,给甲方领导)
```
封面:报告编号/甲方单位+Logo位/乙方/合同号/巡检周期/报告日期
一、巡检概述(范围·方式·人员·时间)
二、总体健康度(评分+分级+环比箭头+达标率)
三、巡检结果总览(设备×状态汇总表:设备名/型号/健康分/结论)
四、异常与建议(序号/设备/巡检项/检查标准/巡检结果/整改建议/期限)
五、下期巡检计划
签字页(巡检人/审核人/甲方接收人 + 双方盖章区)
```

### 模板二《工程明细版》(Word/HTML,给双方工程师)
= 模板一全部 + 逐设备章节:基本信息头 + **巡检明细表(巡检项/巡检内容/检查标准/巡检结果/实测值/备注,华为四列范式扩展)** + 原始命令回显块(证据链)

### 模板三《台账表格版》(Excel,给甲方归档)
- Sheet1 设备台账 / Sheet2 巡检结果矩阵(设备×巡检项着色)/ Sheet3 异常跟踪(含连续期次)

### 交互
巡检完成提示弹窗(桌面版对话框/网页版横幅):三模板**可多选**;默认勾选"正式版+台账版";选择记忆到设置。
