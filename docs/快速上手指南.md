# 快速上手指南(巡检工程师)

> 适用:昊云网络巡检助手 v0.1.0+(2026-11-14)
> 双击「启动巡检助手.exe」即可使用;遇到问题先看文末"常见问题"。

---

## 一、三步完成巡检

```
第 1 步  建档(每单位一次,约 10 分钟)
  客户管理 → 新建客户(填甲方名称/联系人/报告接收邮箱)
  设备管理 → 批量导入(上传您的密码表)或逐台添加
    ├─ 有表格 → 点「批量导入」,自动识别地址/用户名/密码/super密码列
    └─ 没表格 → 点「新建设备」→ 填 IP/用户名/密码 → 点「自动识别」带出厂商/型号

第 2 步  巡检(每次 1 次点击)
  巡检任务 → 按客户筛选 → 点「巡检本单位」→ 确认 → 等完成弹窗

第 3 步  收报告(0 操作)
  完成后点弹窗「是」预览报告;或到报告管理页下载
  ├─ 导出 Word → 选「正式版」(给甲方领导)或「工程版」(给工程师)
  ├─ 导出 Excel → 台账报告(甲方归档)
  └─ 可选邮件发送给甲方接收人
```

## 二、登录方式怎么选

| 场景 | 选什么 | 填法 |
|---|---|---|
| 常规网络设备 | SSH(默认) | IP+用户名+密码+可选super |
| 老设备/封闭内网 | Telnet | 同上,端口自动 23 |
| **甲方不给账号** | **SNMP 只读** | IP+密码栏填 community,端口 161 |
| 防火墙 Web 管理 | Web 页面 | IP+用户名+密码 |
| 深信服 NGAF | API 接口 | IP+token |
| 设备失联/密码遗忘 | Console 串口 | host 填 COM3,port 填波特率 |

## 三、报告怎么读

| 指标 | 含义 | 看哪里 |
|---|---|---|
| **健康分** | 0-100,五类加权;critical 告警强制≤40 | 报告封面/摘要 |
| **安全基线达标率** | 等保 2.0 八项基线达标百分比 | 报告摘要 |
| **上期问题复查** | 上次 FAIL 项本期是否已解决 | Word 报告专章 |
| **连续期次** | 同一异常连续多少期未解决(≥3期标红) | Excel 异常跟踪 Sheet |
| **配置变更** | 与上次巡检的配置差异(增行绿/删行红) | Word 报告专章 |
| **网络拓扑** | LLDP 邻居关系图(蓝=巡检设备,红=异常) | HTML 报告 |

## 四、设备知识库(经验积累)

巡检时系统**自动**把每台设备的全部命令回显存入知识库。

您还可以主动积累:

| 操作 | 入口 | 用途 |
|---|---|---|
| 导入旧巡检报告 | 知识库 → 导入历史资料(上传 Word/txt) | 旧资料变语料 |
| 导入本机报告 | 知识库 → 导入本机报告 | 一键导入全部历史 JSON |
| 载入内置样例 | 知识库 → 内置样例 | 五厂商开箱即有 |
| **AI 解析入库** | 知识库 → 任一回显 → 「AI 解析」 | **离线适配主力**:AI 生成解析规则,确认后下次巡检自动生效 |
| 起模拟器 | 知识库 → 「用此设备起模拟器」 | 无真机演示/培训/自测 |

## 五、无真机环境也能做的事

1. **导入旧资料** → 知识库有语料
2. **AI 解析** → 从语料生成解析规则入库
3. **起模拟器** → 本地 Telnet 模拟设备,巡检全流程可跑
4. **载入内置样例** → 五厂商标准回显即刻可查
5. **定时巡检+邮件** → 设置面板配置自动运行

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 双击没反应 | 看任务栏,可能被遮挡;或杀毒软件拦截 |
| 登录密码 | 默认 admin/admin123,在系统设置修改 |
| 巡检报"网络未通" | 确认设备 IP 可达:cmd → ping 设备IP |
| 巡检报"密码待更新" | 编辑设备修改密码 |
| 某项显示 UNKNOWN | 未知格式:知识库→找到该回显→AI 解析;或真机回传回显给我们 |
| 报告样式要改 | 编辑 config/report_style.yaml(封面色/署名) |
| 数据在哪 | data/patrol.db(主存储)+ config/(配置);备份这两个 |
| 模拟器连不上 | 用 telnet 127.0.0.1 端口 测试;netmiko 对模拟提示符检测过严(真机正常) |

## 八、命令行工具(高级)

```bash
# 全量巡检(所有启用设备)
python -m patrol

# 指定配置与规则
python -m patrol -c config/devices.yaml -r config/rules/default.yaml

# 使用等保基线包
python -m patrol -r config/rules/baseline_dengbao.yaml

# 单设备深度诊断
python scripts/inspect_one.py -n 设备名

# 环境预检(不登录设备)
python scripts/preflight_check.py

# 起模拟设备(演示/测试)
python -m patrol.simulator --seed huawei
python -m patrol.simulator --knowledge 客户/设备

# 环境变量
set PATROL_CONCURRENCY=5   # 并发路数(默认3)
```
